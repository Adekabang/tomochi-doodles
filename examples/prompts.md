# Prompt Examples

The prompts below can be copied directly into Codex.

## Planning Only (No Generation)

```text
Use $ian-xiaohei-illustrations — do not generate images yet.
Analyze this article for illustration opportunities and output a shot list of about 5 images.
For each image, specify:
- Which paragraph it follows
- Image theme
- Core meaning
- Structure type
- What Xiaohei is doing in the image
- Suggested elements
- Suggested Chinese annotation words

<paste article>
```

## Article Inline Illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 Xiaohei absurd inline illustrations for this article.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, sparse red/orange/blue Chinese handwritten annotations.
Each image covers only one core structure — no PPT infographics, no cute cartoons.

<paste article>
```

## Long Article Illustration Strategy

```text
Use $ian-xiaohei-illustrations to plan an illustration strategy for this long article.
Don't illustrate evenly — pick cognitive anchors only: core judgments, input/output loops, before/after contrasts, common pitfalls, handoff paths.
Default 6–8 images, output shot list only, do not generate images.

<paste article>
```

## Single Concept Image

```text
Use $ian-xiaohei-illustrations to generate one 16:9 inline illustration for this idea:

Trust isn't shouted — it's laid down one piece of evidence at a time.

The image should be absurd but clean, and Xiaohei must perform the core action.
Keep Chinese annotations to at most 5, and keep them short.
```

## Workflow Theme

```text
Use $ian-xiaohei-illustrations to generate one image for "turning one piece of raw material into three types of content: traffic, trust, and conversion."
Don't draw a formal flowchart, don't copy the old one-fish-many-uses example.
Please reinvent a new low-tech metaphor, with Xiaohei participating in the core action.
```

## Edit Image: Remove Title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the "Workflow / Flowchart" title and underline in the top-left corner, keep everything else unchanged.
Do not add any new text or objects.
```

## Edit Image: Enhance Xiaohei's Involvement

```text
Use $ian-xiaohei-illustrations — this image has the right direction, but Xiaohei feels a bit decorative.
Keep the core meaning the same, regenerate a version: make Xiaohei the one truly driving the structure.
Make it a bit stranger, but still pure white, clean, and minimal text.
```

## Generate a Style Sample Set

```text
Use $ian-xiaohei-illustrations to output 5 Xiaohei inline illustration concepts for different themes.
Themes cover: information overload, product validation, content compounding, solo business, trust building.
Generate each separately — do not combine into one image.
```
