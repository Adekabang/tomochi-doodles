# README Example Image Prompts

Paste-ready prompts to regenerate the 8 images in the README "Example Output" section.

Run each block separately in ChatGPT web (or Nano Banana / Gemini). Ask for 16:9. Generate one at a time — never combine. Save output to `examples/images/` with the matching filename.

Character DNA is repeated in every block on purpose so each is fully self-contained.
